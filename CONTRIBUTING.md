# Contributing

Open focused issues and pull requests with a reproducible description of the change. Preserve data, keys, access control, API compatibility and both interface languages.

Run the checks in [README](README.md), `python3 scripts/check-public-content.py` and `python3 scripts/check-documentation.py`. Storage-format changes need a documented compatibility and recovery plan and must be tested with disposable data.

Repository guides are written in English and listed with their purpose in `documentation.json`. Keep them focused on using, deploying or developing the software. Update related links when moving a guide. Preserve original dependency notices and attribution.

Contributions must be compatible with the project's license, and contributors must have the right to submit them. Third-party materials retain their own terms.
